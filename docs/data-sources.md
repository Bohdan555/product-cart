# Джерела даних і правила (перевірено 2026-11-14)

Головне правило: беремо дані лише там, де мережа це дозволяє — офіційні канали, фіди за угодою, дані, якими ділиться сам покупець. Сайти й API, умови яких забороняють комерційне використання, не збираємо.

| Мережа | robots.txt | Умови використання | Як беремо |
|---|---|---|---|
| **Сільпо** | Сайт за захистом Cloudflare | Офіційний MCP для AI-застосунків, відкритий самою мережею (хакатон AI Factory) | **MCP від імені покупця** (`productcart silpo …`) |
| **АТБ** | `/catalog/*`, `/product/*` дозволено | «будь-яке копіювання та відтворення даних з сайту дозволено тільки для особистого некомерційного використання» (atbmarket.com/oferta) | **Не збираємо.** Потрібна згода мережі |
| **Zakaz.ua** (NOVUS, Auchan, METRO, ЕКО Маркет, Таврія В…) | Сайт дозволено; `stores-api.zakaz.ua` — `Disallow: /` | «не … використовувати будь-яким способом для будь-яких комерційних цілей Сайт та (або) будь-які частини вмісту Сервісу без згоди Zakaz.ua» (zakaz.ua/uk/page/terms) | **Не збираємо.** Потрібна згода Zakaz.ua |

| **VARUS** | Усе дозволено | Умов не знайдено | **Фід за угодою** (є контакт) |

Правовий контекст: закон № 2811-IX (2022) — авторське право і право sui generis на неоригінальні бази даних. Ціни як факти не охороняються, але систематичне вилучення суттєвої частини бази — ризик.

## MCP «Сільпо»
- Сервер: `https://mcp.silpo.ua/mcp`, Streamable HTTP.
- OAuth 2.1 + PKCE, динамічна реєстрація клієнта (`/register`), авторизація `https://mcp.silpo.ua/authorize` → вхід на `auth.silpo.ua` (телефон + код). Метадані: `/.well-known/oauth-protected-resource/mcp`, `/.well-known/oauth-authorization-server`. Перевірено 2026-11-14: реєстрація й посилання на вхід працюють.
- Каталог доступний лише в сесії покупця.
- Інструменти, які використовуємо: `silpo_list_branches`, `silpo_get_time_slots` (контекст магазину), `silpo_get_promotions` (коди акцій), `silpo_get_products` з `promotionCode` (товари з `price`/`oldPrice`), `silpo_get_my_food_restrictions`, `silpo_get_my_family` (підказки для профілю). Повний список із 40 інструментів — у відкритих проєктах хакатону: [SilpoRestockAI](https://github.com/javaAndScriptDeveloper/SilpoRestockAI), [ai-silpo](https://github.com/VictorYarosh/ai-silpo).
- Умов для сторонніх комерційних продуктів «Сільпо» не опублікувало — перед публічним запуском узгодити з мережею.

## Інші законні джерела (план)
- **Фіди мереж за угодою** — формат у `feed-format.md`.
- **Дані від покупців:** фото чека чи цінника. QR фіскального чека містить лише суму; позиції віддає реєстр ДПС за особистим токеном, але, за відкритими проєктами, під час воєнного стану доступ обмежено (не перевірено напряму).
