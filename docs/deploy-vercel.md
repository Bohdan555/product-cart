# Деплой на Vercel

Сайт працює як Python-функція Vercel (`api/index.py` → FastAPI), усі адреси переписуються на неї (`vercel.json`). Дані — у Postgres (Neon через Vercel Marketplace): на Vercel немає постійного диска, тож SQLite там не підходить.

## Кроки (один раз, ~5 хвилин)
1. **Акаунт.** vercel.com → **Sign Up → Continue with GitHub** (план Hobby — безкоштовний, лише для некомерційного використання; для комерційного — Pro).
2. **Проєкт.** **Add New → Project** → репозиторій `product-cart` → **Import**. Framework Preset: **Other**. Нічого не змінюйте й не натискайте Deploy, доки не додасте змінні (крок 4), або натисніть — перший деплой просто впаде без секрету, це не страшно.
3. **База.** У проєкті: **Storage → Create Database → Neon (Postgres)** → регіон **Frankfurt (fra1)** → **Connect** до проєкту. Vercel сам додасть `DATABASE_URL`.
4. **Змінні.** **Settings → Environment Variables**:
   - `APP_SECRET` — довгий випадковий рядок (згенеруйте у себе: `python3 -c "import secrets; print(secrets.token_urlsafe(32))"`). Шифрує токени «Сільпо»; якщо змінити — усім доведеться підключити «Сільпо» знову.
   - `BASE_URL` — необов'язково: якщо не задано, береться production-адреса проєкту (`https://my-product-cart-ua.vercel.app`). Задайте, якщо підключите свій домен.
5. **Регіон функцій** (бажано поруч з базою): **Settings → Functions → Function Region → Frankfurt (fra1)**.
6. **Deploy** (або **Deployments → Redeploy**). Далі кожен push у `main` деплоїть автоматично.

## Перевірка
Відкрийте `https://my-product-cart-ua.vercel.app/` → зареєструйтеся → профіль → **Підключити «Сільпо»** → вхід на сторінці «Сільпо» → оберіть магазин → **Мій список**.

Адреса повернення для «Сільпо» — `BASE_URL/auth/silpo/callback`; застосунок реєструється в «Сільпо» автоматично при першому підключенні.

## Обмеження
- Перше завантаження акцій магазину може тривати до кількох десятків секунд (ліміт функції — 60 с, `vercel.json`); далі діє кеш на 6 годин.
- Preview-деплої (гілки, PR) мають іншу адресу: вхід у «Сільпо» там поверне на production-адресу, тож тестуйте «Сільпо» на production.

## Статистика
Сторінка `/admin/stats` (і пункт меню «Статистика») доступна лише акаунтам, чиї email перелічені в змінній `ADMIN_EMAILS` (через кому): **Settings → Environment Variables → `ADMIN_EMAILS`**, потім Redeploy. Там: користувачі, активні за 7 і 30 днів, воронка, перегляди й переходи по днях, категорії, мережі, магазини й глибина знижок, на які реагують. Лише сукупні числа, без персональних даних.
