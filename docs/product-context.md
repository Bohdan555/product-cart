# Контекст продукту «Кошик з акцій» (читати за потреби)

## Що вміє (листопад 2026)
- **Найближчий «Сільпо»** на головній (з підключеним «Сільпо» — при відкритті сам перемикає «мій магазин» на найближчий за GPS, `POST /silpo/nearest`, ≤ 50 км; дозвіл питаємо одразу; на інших сторінках — тихий скрипт у `base.html` раз на 20 хв, оновлює й збережене місце `p.lat` для «Акцій»): одразу за IP (заголовки Vercel), потім за геолокацією телефона (дозвіл раз; відмова → `localStorage geo-no`), `GET /near?lat&lon` з кешу `silpo_branches`, координати округлені до 0,001 і не зберігаються, не далі 50 км.
- **Головна-вітрина** (`templates/home.html`): зелена шапка з магазином і пошуком (→ `/today`), 8 розділів, банер меню тижня, каруселі «Гарячі акції» (кеш магазину або демо) і швидких страв (`menu.today`, 30 хв).
- **Сьогодні** (`/today` → `/today/dishes` → `/today/dish/{id}`): ввід «що є» текстом або голосом (`_say.html`), 3 страви + «⇄ Інша» (пул 30), сніданок/обід/салат, кухонні прилади (`k=`), калорії.
- **Тиждень**: `/week` → «Що є вдома» (`/fridge`, фото холодильника розпізнає Claude) → `/menu` одразу (конструктора немає: `/menu/setup` → `/menu`; зверху чипи 👥/📅/⏱/💰 з нижнім вікном → `POST /menu/settings`) (блок економії, рядки страв, заміна) → `/buy` (список, позначки «куплено», копія в месенджер) → кошик «Сільпо».
- **Холодильник** `/pantry` (окрема сторінка; вхід з головної `.hm-fridge` і профілю): групи «Використати скоро / Цього тижня / Довго / Інше», додати текстом/голосом (`_say.html`) або фото (`/fridge/scan`) → `POST /pantry/add`; торкнувся рядка — аркуш з датою (`/fridge/expiry`) і «Прибрати» (`/pantry/remove`). Зіпсоване >2 днів тому прибирається само (`prune_fridge`), тижневого очищення більше немає.
- **Скоро зіпсується**: `menu.SHELF_DAYS` (типові дні в холодильнику) + `Profile.fridge_since`; ручна дата з упаковки — `Profile.fridge_until` (блок «Термін придатності» на `/fridge`, `POST /fridge/expiry`, важливіша за оцінку, `menu.use_by`) (коли продукт з'явився вдома — з «Що є вдома»). `menu.expiring()` → блок «Варто використати» на головній (сьогодні/завтра), такі продукти підіймають страви в «Сьогодні» (`soon`), щоранку лише push на телефон, не Telegram (`tg_expiry`, раз на день, ключ `x:<дата>` у `tg_sent`). «Приготовано» прибирає швидкопсувне з рецепта з холодильника.
- **Акції** `/list`: сітка карток з фото, фільтри категорій, «+ У кошик» (з «Сільпо»), стежити 🔔.
- **Профіль** `/me`: Готую, Меню на тиждень, **Смаки й харчування** (`/profile`: плитки смаків, дієти, що купуєте щотижня, знижки — одна сторінка; гостю — крок смаків конструктора), Мої страви (`/dishes`, імпорт рецепта за посиланням), «Сільпо», Сповіщення (Web Push + Telegram).
- **PWA**: маніфест, service worker (офлайн), web push (VAPID з `APP_SECRET`), іконка — золотий кошик зі «%» на пляшково-зеленому (`static/icons/`).

## Ціни без підключеного «Сільпо»
- MCP «Сільпо» без входу відповідає 401. Для рецептів («Сьогодні», меню тижня) гість і непідключений отримують ціни зі **спільного кешу** `offers_cache`: найближчий магазин (профіль або IP) з кешем ≤ доби, інакше найсвіжіший будь-який; демо — лише коли кешу немає.
- **Службове підключення** (адмінка `/admin/stats#silpo`, налаштування `silpo_donor`, зашифровано; окремо від особистого «Сільпо» адміна). Ним оновлюємо кеш для цін **інгредієнтів рецептів**: у фоні після відповіді (`warm_soon` → `warm_store`, ≤ 1 раз/10 хв на магазин), синхронно — якщо кешу немає зовсім, і щодня `/cron/warm` (магазини з `warm_demand` за 7 днів, до 8).
- **Акції** (`/list`, «Гарячі акції» на головній) — лише з власним підключеним «Сільпо»; гостю й непідключеному — запрошення підключити (`list_locked.html`), демо там більше немає.
- Умови «Сільпо» щодо показу цих даних іншим людям — уточнити (запропоновано написати їм про партнерський фід).

## PostHog (EU)
- `web/posthog.py`: усі події `analytics.track` дублюються в PostHog пакетом після відповіді (без email/координат; користувач — псевдонім `u_<HMAC>`; гість без згоди — подія без профілю). Ключ — env `POSTHOG_KEY` (Vercel), хост `POSTHOG_HOST` (за замовчуванням `https://eu.i.posthog.com`). Без ключа вимкнено.
- Браузер: банер згоди (`#phConsent`, cookie `pc_an`), після «Дозволити» — `array.js` з `eu-assets`, перегляди (history_change), запис сеансів з маскуванням вводу, `identify` тим самим псевдонімом. Скинути — на `/privacy#analytics`.

## Адмінка
- `/admin/stats` (посилань у шапці й профілі немає — лише за адресою): статистика, воронка, **використання функцій** (`analytics.FEATURES`/`FLOWS`: 7/30 днів, люди, частка гостей; шляхи «Сьогодні» й «Тиждень»), оцінки рецептів (👍/👎). Доступ — email з `ADMIN_EMAILS` (Vercel env, production). Без входу → `/login?admin=1`, після входу повертає назад (cookie `after_login`).

## Важливі рішення
- Смаки — на сторінці «Смаки й харчування» (`/profile`). Меню тижня складається одразу за звичними значеннями; змінити — чипами зверху.
- «Зекономлено» в профілі прибрано; економія показується лише в меню тижня (без знака «−»).
- Демо-товари отримують стокові фото з Unsplash (`PRODUCT_QUERIES`, ключ `p:<id>`), автори — на `/photos`. Товари «Сільпо» мають власні фото з MCP.
- Головна читає лише кеш акцій (`cached_offers`), щоб відкриватись ~0,4 с.
- Шрифти системні: ліцензія Apple не дозволяє вбудовувати SF у сайт.
- Заблоковано: справжнє «Купив» за історією замовлень «Сільпо» — запропоновано, користувач не підтвердив.
