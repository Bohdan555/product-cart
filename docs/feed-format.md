# Формат фіду акцій від мережі

CSV (UTF-8, роздільник кома) або JSON (`[{...}]` чи `{"offers": [...]}`). Один рядок — одна акційна пропозиція.

| Поле | Обов'язкове | Приклад | Опис |
|---|---|---|---|
| `chain` | так | `varus` | ключ мережі |
| `product_id` | так | `123456` | артикул мережі |
| `name` | так | `Гречка ядриця 1 кг` | назва з вагою чи об'ємом |
| `price` | так | `44.90` | акційна ціна, ₴ (крапка або кома в лапках) |
| `old_price` | ні | `57.90` | ціна без акції |
| `valid_to` | ні | `2026-11-20` | останній день акції |
| `brand`, `category` | ні | `Хуторок`, `Крупи` | для фільтрів і пояснень |
| `pack_qty`, `pack_unit` | ні | `1000`, `g` | якщо немає — розбираємо з назви (`g`, `ml`, `pcs`) |
| `weighted` | ні | `true` | ваговий товар, ціна за кг |
| `store_id`, `store_name` | ні | `kyiv-12`, `Київ, Хрещатик 1` | якщо акція діє не в усіх магазинах |
| `promo` | ні | `Ціна тижня` | назва акції або умова («2 за ціною 1», «за карткою») |
| `ean` | ні | `4820000000000` | штрихкод |
| `url`, `image` | ні | | посилання на товар і фото |
| `tags` | ні | `gluten\|dairy` | власні теги через `\|`; інакше визначаємо за назвою |

Перевірка: `productcart -v list --source feed:шлях/до/фіду.csv --profile profiles/example.json`
