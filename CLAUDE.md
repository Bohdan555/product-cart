# Product Cart — правила репозиторію

Мова спілкування з користувачем: українська.

## Мета
Застосунок, який збирає вподобання людини і, оперуючи акціями мереж, складає готовий список покупок у магазинах поблизу. Етап 1 (зараз): збір даних і готовий список. Доставка — пізніше.

## Git
- Усі коміти лише від імені `bohdan <bohdan549@gmail.com>`.
- Не додавати в повідомлення комітів `Co-Authored-By`, `Claude-Session` чи інші позначки співавторства.
- Гілка за замовчуванням — `main`.

## Дані (обов'язково)
- Лише законні джерела: офіційний MCP «Сільпо» від імені покупця, фіди мереж за угодою, дані від самих покупців, демо.
- **Не збирати** сайти й API АТБ і Zakaz.ua (і будь-які інші, де умови забороняють комерційне використання) без письмової згоди. Деталі: `docs/data-sources.md`.
- Токени, профілі реальних людей і вивантаження (`.secrets/`, `profiles/*.json` крім прикладу, `out/`) не комітити.
- Демо-дані позначені як вигадані (`chain` = `demo-*`).

## Код
- Python ≥ 3.11, ядро без залежностей; `mcp` 1.x лише для «Сільпо» (`pip install -e '.[silpo]'`).
- Числа, бали й фільтри рахує код, без LLM.
- Нове джерело = модуль у `productcart/sources/`, що повертає `list[Offer]`, і тести на фікстурах (без мережі).
- Перед комітом: `.venv/bin/python -m pytest -q`.
