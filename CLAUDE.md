# Кошик з акцій — правила й контекст

Мова спілкування: українська. Відповідай коротко, по суті; деталі — у `docs/product-context.md` (читай лише коли потрібно).

## Продукт
PWA-сайт: «що приготувати з того, що є» + меню на тиждень з акцій «Сільпо» + список/кошик покупок.
Живий сайт: https://my-product-cart-ua.vercel.app · репозиторій `Bohdan555/product-cart` (гілка `main`).

## Стек
FastAPI + Jinja + Turbo 8 (`productcart/web/`), ядро без веб-залежностей (`models, catalog, matcher, planner, menu, render`).
Neon Postgres на Vercel, SQLite локально й у тестах. «Сільпо» — офіційний MCP (`sources/silpo*.py`). Фото страв і демо-товарів — Unsplash API (`web/unsplash.py`).

## Робочий цикл (економно)
1. Шукай `grep`/`sed -n` по рядках, не читай великі файли цілком (`web/app.py` ~2.4k рядків, `static/style.css` ~1.5k).
2. Перед комітом: `.venv/bin/python -m pytest -q` (зараз 147 тестів); комітити лише якщо він пройшов — `pytest -q && git commit …`, не через `| tail`.
3. Коміт: `git -c user.name=… -c user.email=…` (автор — з розділу Git), потім `git push -q origin main`.
4. Деплой — ОКРЕМОЮ командою від коміту: `vercel deploy --prod --yes --token proxyinjectedplaceholder00`.
5. Візуальна перевірка: локально `DB_PATH=<scratch>/x.db APP_SECRET=<16+ символів> .venv/bin/uvicorn api.index:app --port 8765` + Playwright (iPhone 13), знімки до/після.
6. Логи: `vercel logs --since 59m --json` (Hobby тримає 1 год).
7. Тестування сайту: агент `qa-tester` (`.claude/agents/qa-tester.md`) або напряму `node tools/qa/smoke.js <URL> <out> [--login]`.

## Дизайн (коротко)
- **UI/UX-правила — `docs/ux-principles.md` (прочитай перед будь-якою зміною інтерфейсу)**: одна головна дія на екран, мінімум тексту, автозбереження, звичні патерни, чек-лист. Перевірка — агент `ux-reviewer`.
- **Стиль — «Liquid Glass» за Apple HIG (iOS 26)**, шар у кінці `static/style.css`. Деталі й правила — `docs/ux-principles.md` §9.
- Палітра: вдень фон `#F4F2EE`, картки `#FFF`, головна дія — бренд-зелений `#1D3B2F`, золото `#C9A45C` для акцентів; вночі фон `#000`, картки `#1C1C1E`, акцент шампань `#D4B37A`.
- Скло (`--glass`, blur) — лише для елементів керування над змістом: таб-бар-капсула, «назад», підказки, кнопки на фото. Зміст — без скла.
- Типографіка HIG (системний SF Pro): Large Title 34 · Title2 22 · Title3 20 · Body 17 · Subheadline 15 · Footnote 13. Радіуси концентричні 10/14/20/26/32, кнопки — капсули.
- Контраст тексту ≥ 4,5; зони дотику ≥ 44 px; емодзі — лише для продуктів/страв, в інтерфейсі — іконки з `web/icons.py`. Повага до «Зменшити рух» і «Зменшити прозорість».
